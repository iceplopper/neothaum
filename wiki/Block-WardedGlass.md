A **Warded Glass** is a block added by **NeoThaum** (recreating Thaumcraft 4 for modern Minecraft).

## Obtaining

### Breaking

A **Warded Glass** can be mined using an appropriate tool (recommended: **Pickaxe**). When broken with the required tool, it drops its corresponding block item.

### Crafting

| Recipe File | Type | Ingredients |
| :--- | :--- | :--- |
| `wardedglass.json` | Arcane_Shaped | Zombie Brain, Greatwood Planks, Glass |

## Usage

The **Warded Glass** has several important interactions:

- **Inspection**: Can be scanned with a [Thaumometer](Scanning-&-Thaumometer) or inspected with [Goggles of Revealing](Item-GogglesOfRevealing).
- **Thaumaturgical Function**: Participates in environmental aura mechanics, essentia transfer, or multiblock structure arrays.
