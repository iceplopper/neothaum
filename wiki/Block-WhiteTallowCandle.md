A **White Tallow Candle** is a block added by **NeoThaum** (recreating Thaumcraft 4 for modern Minecraft).

## Obtaining

### Breaking

A **White Tallow Candle** can be mined using an appropriate tool (recommended: **Hand / Instant**). When broken with the required tool, it drops its corresponding block item.

The **White Tallow Candle** has several important interactions:
