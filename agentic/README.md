# Agentic Workspace & AI Handoff Directory

> **STRICT RULE FOR ALL AI ASSISTANTS (Claude, Gemini, etc.):**  
> Anything that is **not pertinent to the mod itself** MUST be kept inside this `agentic/` directory.  
> Do NOT create loose markdown notes, handoff files, TODOs, scratchpad scripts, or diagnostic logs in the root project folder. Keep the root directory clean and strictly focused on source code, gradle build files, and runtime resources.

---

## Directory Organization
- `agentic/TODO.md` — The active, prioritized master task list containing all user feedback, bug reports, visual audits, and pending features.
- `agentic/HANDOFF.md` — Current handoff briefing and instructions for Claude to resume development.
- `agentic/HANDOFF_HISTORY.md` — Historical chronological record of past commits and transitions.
- `agentic/TC4_REMAINING.md` — Complete TC4 feature audit checklist.
- `agentic/CLAUDE.md` — Full project context and operating guide for Claude Opus in Claude Code CLI.
- `agentic/logs/` — Any diagnostic outputs, test logs, or temporary execution logs (`gametest.log`, `runclient.log`, etc.).
