# NeoThaum 1.0.7 (alpha)

Includes everything from [1.0.6](https://github.com/iceplopper/neothaum/releases/tag/v1.0.6-alpha), plus the changes below.

Two downloads:
- **`neothaum-1.0.7.jar`:** the mod alone.
- **`NeoThaum-1.0.7.mrpack`:** a Modrinth modpack. It contains the mod with Fabric API, ModMenu, JEI, Jade and Xaero's Minimap and World Map, set up for Minecraft 26.3 with Fabric Loader 0.20.1.

## Minor features

- **Biome versions of the village buildings:**
  - **Desert:** the wizard tower and banker houses are built in sandstone, following TC4's own desert rule.
  - **Savanna:** acacia.
  - **Taiga and snowy:** spruce.
  - **Villagers:** each wizard and banker wears its village's clothes.
- **Windows and counters:** the wizard tower's glass panes and the banker's counter bars now join the walls instead of standing as thin posts. Towers already generated in a world keep their old panes.
